🏥 Aplikasi Manajemen Klinik (Bengkel Koding)

Proyek sistem informasi manajemen klinik berbasis web yang dibangun menggunakan **Laravel**. Aplikasi ini dirancang untuk mendigitalisasi alur pendaftaran pasien, pengelolaan poliklinik, jadwal periksa dokter, hingga proses pemeriksaan dan resep obat.

## ✨ Fitur Utama
* **Admin:** Mengelola data master seperti Dokter, Pasien, Obat, dan Poliklinik.
* **Dokter:** Mengatur jadwal periksa, memeriksa pasien, memberikan catatan/diagnosa, dan mengelola resep obat.
* **Pasien:** Melakukan registrasi, memilih poliklinik, dan mendaftar antrean pemeriksaan.

## 🛠️ Tech Stack
* **Framework:** Laravel
* **Frontend:** Blade Templating, Tailwind CSS
* **Database:** MySQL / SQLite
